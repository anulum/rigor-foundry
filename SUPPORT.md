# Support

Use the channel that matches your request.

- Ask usage questions in [Discussions Q&A](https://github.com/anulum/rigor-foundry/discussions/categories/q-a).
- Discuss early proposals in [Discussions Ideas](https://github.com/anulum/rigor-foundry/discussions/categories/ideas).
- File reproducible defects and concrete capability requests through the
  [issue forms](https://github.com/anulum/rigor-foundry/issues/new/choose).
- Report suspected vulnerabilities privately through the [security policy](SECURITY.md).
- Report conduct concerns privately through the
  [participation standard](CODE_OF_CONDUCT.md#reporting-and-enforcement).

The [security policy](SECURITY.md#supported-versions) defines the supported
release and branch for security reports. The
[governance policy](GOVERNANCE.md#community-stewardship) identifies the triage,
moderation and escalation owner. Keep credentials, proprietary source, private
audit reports and secret variable values out of public Issues and Discussions.
